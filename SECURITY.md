# Security policy

## Supported versions

Until the first stable release, security fixes target the latest revision on the default branch.

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature when it is enabled for the repository. Include reproduction steps, affected files or versions, impact, and any suggested mitigation.

This is a local application, but reports involving filesystem boundaries, command execution, media parsing, local network exposure, path traversal, or unintended publication are treated as security-sensitive.
